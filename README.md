# HTML Editor – Výuka a procvičování HTML

Jednoduchá statická webová aplikace pro výuku a procvičování psaní HTML kódu, plně přizpůsobená a optimalizovaná pro mobilní dotyková zařízení i stolní počítače.

---

## Hlavní vlastnosti

1. **Vkládání prvků (Drag & Drop + Tap)**
   - Panel nástrojů obsahuje všechny základní HTML elementy rozdělené do kategorií pomocí výběrového pole (select).
   - Karty elementů zobrazují přehledně pouze svůj HTML tag (např. `<h1>`, `<p>`, `<img>`...).
   - **Mobilní přetažení:** Při otevřeném panelu na mobilním zařízení a zahájení tahu za kartu se panel ihned automaticky skryje, aby byl plně vidět prostor s kódem. Prvek lze tažením pustit na libovolný řádek.
   - **Klepnutí pro rychlé vložení:** Klepnutím na kartu se prvek vloží na aktuální pozici kurzoru a panel se zavře.

2. **Editor a Náhled**
   - Jednoduché přepínání mezi záložkami **Editor** a **Náhled**.
   - Náhled se zobrazuje přes celou plochu s tlačítkem pro okamžité obnovení.

3. **Čistá lišta nástrojů**
   - Kompaktní lišta obsahuje pouze nejdůležitější akce: **Zpět**, **Znovu** a **Formátovat**.

4. **Nastavení vzhledu**
   - Možnost přepínání mezi světlým a tmavým motivem.

---

## Jak aplikaci spustit

- **V prohlížeči:** Otevřete přímo soubor `index.html`.
- **Na lokálním serveru:** Spusťte `python -m http.server 8000` a přejděte na adresu `http://localhost:8000`.
